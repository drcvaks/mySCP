# mySCP App Icon

`myscp-app-icon-v2.png` is the master Home Screen/install artwork, created with
the built-in image-generation tool using `SCP Icon.png` as a brand reference.
The original printed-material logo is not replaced.

Prompt: Create a polished square mySCP Home Screen icon with a recognizable
three-strand SCP flame, white and pale-gold flame strands on royal blue, and
large, legible "mySCP" lettering. Keep essential artwork centered, with no tiny
program subtitle, outer rounded corners, transparency, download arrow, or mockup.

Generate the production PNG sizes with `node scripts/prepare_pwa_icons.cjs`.
